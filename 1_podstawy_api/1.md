## Zadanie 1

Twoim zadaniem jest wygenerowanie nowego projektu w NestJS oraz zmodyfikowanie plików `app.controller.ts` i `app.service.ts`, aby kontroler działał w następujący sposób:

1. Element "/solvro" ma być ustawiony globalnie dla całego kontrolera (dla wszystkich endpointów w nim zawartych).
2. Utwórz endpoint z metodą GET pod adresem `http://127.0.0.1/solvro`, który dokona przekierowania na stronę KN Solvro (https://solvro.pwr.edu.pl), zwracając przy tym manualnie ustawiony kod statusu 307.
3. Utwórz drugi endpoint z metodą GET pod adresem `http://127.0.0.1/solvro/brewCoffee`, który zwróci manualnie ustawiony kod statusu 418 oraz JSON w postaci:
```json
{
    "message": "I'm a teapot",
    "funnyPictureURL": "https://http.cat/images/418.jpg"
}
```
4. Dla endpointu `brewCoffee` ustaw nagłówek `Content-Type` na `"application/json"`.
5. Wykonaj zapytania do obu utworzonych endpointów z klienta API (przykładowo Postman), aby zweryfikować poprawność działania.

### Jak zabrać się za to zadanie?

1. Wejdź na swój główny branch i pobierz aktualny stan (`git checkout jan-kowalski && git pull`). Jeśli masz już zmergowane poprzednie zadanie - wyczyść folder z jego zawartości (łącznie z `package.json` i `node_modules/`, żeby nie kolidowały z nowym projektem). Jeśli nie masz jeszcze zmergowane - nic straconego, po prostu nie musisz nic usuwać
2. Stwórz branch pod to zadanie ze swojego głównego brancha: `git checkout -b jan-kowalski-1`
3. Wygeneruj nowy projekt NestJS (`npx @nestjs/cli new nazwa-projektu`, nazwę wybierz dowolną) i upewnij się, że jego zawartość ląduje w głównym folderze Twojego brancha, a nie w osobnym podfolderze
4. Zmodyfikuj `app.controller.ts` i `app.service.ts` zgodnie z treścią zadania
5. Uruchom projekt lokalnie (`npm run start:dev`) i przetestuj oba endpointy klientem API (np. Postman - patrz materiały)
6. Jak skończysz - zacommituj zmiany, wypchnij branch (`git push`) i utwórz Pull Request z `jan-kowalski-1` do `jan-kowalski`
7. W utworzonym PR oznacz jako reviewera TYLKO przypisaną Ci osobę (info kogo oznaczyć znajdziesz na Discordzie, tak jak w poprzednim zadaniu)
